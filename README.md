## 作成するテキスト

| 区分 | 目的 |
|---|---|
| `text/diplomatic/` | 原本の表記・語法・ページ境界をできるだけ保持した翻刻 |
| `text/normalized/` | 検索・通読しやすいよう、一定の方針で字体や句読点等を整理した本文 |
| `data/` | 画像対応表、訂正履歴、判読状況などの構造化データ |

翻刻・正規化の詳細は [`docs/transcription-policy.md`](docs/transcription-policy.md) に記録します。

## 基本方針

1. 主底本の画像から独自に翻刻する。
2. 現代の市販校訂版・現代語訳・注釈を転載しない。
3. 判断を伴う補訂、正規化、判読不能箇所を明示する。
4. 原画像のコマ番号と本文の対応を追跡可能にする。
5. OCRは補助として利用し、公開本文は人手で確認する。
6. 訂正履歴を残し、検証可能なテキストを育てる。
