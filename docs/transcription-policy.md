# 翻刻・正規化方針

## 1. 目的

本方針は、『三酔人経綸問答』の原画像から、検証可能で再利用しやすいテキストを作成するための編集規則を定めるものです。

本プロジェクトでは、次の二層を分けて管理します。

1. **忠実翻刻（diplomatic transcription）**：原本の表記とページ境界をできるだけ保持する。
2. **正規化本文（normalized text）**：検索と通読の利便性を高めるため、明示した規則により表記を整理する。

正規化本文は忠実翻刻から派生させ、根拠のない本文改変を行いません。

## 2. 資料の優先順位

1. **主底本**：弘前市立弘前図書館所蔵本（国書データベース書誌ID 300011691、請求記号304-bN）
2. **対校資料**：国立国会図書館所蔵本その他の公開刊本
3. **参考資料**：稿本、同時代資料、現代の研究文献

市販の現代校訂版、現代語訳、注釈書は、疑問箇所を調べる参考資料として利用できますが、その本文、句読点、ルビ、注釈等を転載しません。最終判断は公開された一次資料へ戻って確認します。

## 3. 共通原則

- 原画像の画像番号と翻刻箇所の対応を維持する。
- 原文にない文字や句読点を黙って補わない。
- 判読不能、推定、補訂、異同を区別する。
- OCR結果は下書きとしてのみ利用し、人手で画像と照合する。
- 重要な訂正は履歴として残す。
- Unicodeで安定して扱えない字は、代替表記と注記を併用する。

## 4. 忠実翻刻の規則

### 4.1 ページ境界

国書データベースの画像番号ごとに、次のHTMLコメントを挿入します。

```markdown
<!-- source-image: 33 -->
```

原本に印刷された丁付・ページ番号がある場合は、画像番号とは別に記録します。画像と印刷ページの対応は `data/page-map.csv` で管理します。

### 4.2 改行と段落

- 段落の区切りは原本に従います。
- 原本の版面上の折返しは、意味上の改行でない限り本文には再現しません。
- 見出し、話者名、章節等はMarkdownの構造として表せる範囲で記録します。

### 4.3 字体・異体字

- Unicodeで安定して表現できる旧字体・異体字は、原則として原字を保持します。
- デバイスやフォントによって表示が著しく不安定な字は、読みやすい代替字を本文に置き、注記を付します。
- いわゆる包摂字形の細かな字形差は、通常のUnicode文字で表します。
- 外字を画像として収録しません。

外字・特殊字の暫定表記は次の形式とします。

```text
[外字:説明]
```

例：

```text
[外字:木偏に某]
```

### 4.4 ルビ

原本のルビを記録する場合は、次の形式を用います。

```text
{親文字|ルビ}
```

例：

```text
{経綸|けいりん}
```

ルビの範囲が不明確な場合は、注記またはIssueで判断を保留します。

### 4.5 句読点・記号

- 原本にある句読点・記号は保持します。
- 原本にない句読点は忠実翻刻へ追加しません。
- 反復記号、踊り字、合字は、可能な限り原字を保持します。
- 横書き環境で意味が変わる記号は、必要に応じて注記します。

### 4.6 判読不能・推定・補訂

| 状態 | 表記 | 例 |
|---|---|---|
| 一字以上判読不能 | `[判読不能]` | `天下は[判読不能]なり` |
| 字数が推定できる判読不能 | `[判読不能:2字]` | `[判読不能:2字]` |
| 読みの推定 | `〔推定字?〕` | `〔自由?〕` |
| 原本の欠損 | `[欠損]` | `[欠損:約3字]` |
| 編集者による補い | `〈補:文字〉` | `〈補:之〉` |
| 原本の明白な誤植 | 原文を保持し注記 | `某字<!-- 原本ママ -->` |

確定できない箇所を、文脈だけで断定的に補いません。

### 4.7 抹消・挿入・傍記

刊本に訂正、抹消、書入れ等が確認された場合は、本文と区別して注記します。頻出する場合は、TEI等の構造化形式の導入を別途検討します。

## 5. 正規化本文の規則

正規化本文は、原文の意味、語彙、文法、歴史的表現を維持しつつ、検索と通読を助けるものです。

当初は次の範囲を正規化対象とします。

- 旧字体を対応する新字体へ置換
- 異体字を一般的な字体へ統一
- 明らかな活字上の揺れを統一
- 必要最小限の句読点と段落を追加
- ルビ記法を読みやすい形へ変換

当初は原則として次を行いません。

- 現代語訳
- 語彙の現代化
- 文法の書換え
- 内容の要約
- 歴史的仮名遣いの全面的な現代仮名遣い化

正規化の範囲を拡張する場合は、本方針と変更履歴を先に更新します。

## 6. 訂正と校訂記録

重要な変更は `data/corrections.csv` に記録します。少なくとも次を残します。

- 対象ファイルまたはアンカー
- 画像番号
- 変更前と変更後
- 変更理由
- 根拠資料
- 状態
- 更新日

単純な誤記修正でも、本文解釈に影響するものは記録対象とします。

## 7. 作業状態

`data/page-map.csv` の `status` には、原則として次を使用します。

- `not_started`：未着手
- `draft`：初回翻刻済み、未照合
- `transcribed`：原画像との一次照合済み
- `reviewed`：別の確認者または独立した再照合済み
- `blocked`：判読・画像・資料上の問題で保留

## 8. 品質確認

公開版に含めるページは、原則として次を満たすものとします。

- 画像番号が記録されている
- 原画像と一度以上照合されている
- 判読不能箇所が明示されている
- 無断の画像転載を含まない
- 市販校訂版等からの転載を含まない
- 修正履歴が必要な変更は記録されている

## 9. 方針の改訂

本方針自体も暫定版です。実際の版面、文字、ルビ、記号の状況に応じて改訂します。変更時は、既存本文への影響と移行方法を明記します。
