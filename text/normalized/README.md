# 正規化本文

忠実翻刻を基礎として、検索と通読の利便性を高めた本文を収録します。

## 本文ファイル

本文の正規化開始時に、原則として次のファイルを作成します。

```text
san-suijin-keirin-mondo.md
```

ファイルを分割する場合は、忠実翻刻側との対応が追跡できる構成にします。

## 当初の正規化範囲

- 旧字体を対応する新字体へ置換
- 異体字を一般的な字体へ統一
- 明らかな活字上の揺れを統一
- 必要最小限の句読点と段落を追加
- ルビ記法を読みやすい形へ変換

## 行わないこと

- 現代語訳
- 語彙の現代化
- 文法の書換え
- 内容の要約
- 歴史的仮名遣いの全面的な現代仮名遣い化

正規化本文で判断が必要な場合は、忠実翻刻と主底本画像へ戻って確認します。規則の追加・変更は、先に [`../../docs/transcription-policy.md`](../../docs/transcription-policy.md) へ反映します。

## ページ対応

通読性を損なわない範囲で、原画像との対応を維持します。少なくとも、忠実翻刻側の画像番号へ戻れるアンカーまたは区切りを残します。
