# 忠実翻刻

主底本の表記、語法、ルビ、記号、ページ境界をできるだけ保持した翻刻を収録します。

## 本文ファイル

本文の翻刻開始時に、原則として次のファイルを作成します。

```text
san-suijin-keirin-mondo.md
```

分量や共同作業上の必要に応じ、画像範囲または章節ごとに分割できます。その場合も、連結順がファイル名から明確になるようにします。

## ページ境界

各画像の冒頭には、国書データベースの画像番号をHTMLコメントで記録します。

```markdown
<!-- source-image: 33 -->
```

## 編集記号

主要な編集記号は次のとおりです。詳細は [`../../docs/transcription-policy.md`](../../docs/transcription-policy.md) を参照してください。

| 内容 | 表記例 |
|---|---|
| ルビ | `{経綸|けいりん}` |
| 判読不能 | `[判読不能]` |
| 字数推定付き判読不能 | `[判読不能:2字]` |
| 推定読字 | `〔自由?〕` |
| 欠損 | `[欠損:約3字]` |
| 編集者による補い | `〈補:之〉` |
| 外字 | `[外字:説明]` |

## 注意

- 現代的な句読点や段落は、原本にない限り忠実翻刻へ追加しません。
- 原本の明白な誤植も黙って直さず、原文を保持して注記します。
- 原画像やスクリーンショットはこのディレクトリへ保存しません。
